# Перенос стиля русской классической литературы с помощью ruT5

Дообучение русскоязычной sequence-to-sequence модели для преобразования классической прозы в современную разговорную речь с сохранением исходного смысла.

## Цель проекта

Проверить, может ли компактная модель научиться менять стиль текста, а не просто копировать входное предложение. Основная сложность задачи заключается в том, что большая часть целевого текста совпадает с исходным, а стилистическое преобразование часто выражается заменой всего нескольких слов.

Пример работы финальной модели:

| Исходный текст | Предсказание |
|---|---|
| Этот молодой человек произвел на меня неприятное впечатление. | этот молодой чел произвел на меня кринжовый вайб. |
| Мне совершенно не хочется сегодня работать. | мне совершенно не хочется сегодня воркать. |
| У него совсем не осталось денег. | у него совсем не осталось кэша. |

## Результаты

Финальная модель оценивалась на 905 ранее не встречавшихся парах предложений. В качестве baseline используется копирование исходного текста без изменений.

| Модель | BLEU | chrF | Style marker rate | Marker recall | Exact copy rate |
|---|---:|---:|---:|---:|---:|
| Identity baseline | 69.79 | **81.71** | 0.22% | 0.11% | 100.00% |
| Fine-tuned ruT5 | **71.17** | 81.52 | **34.81%** | **13.74%** | **54.48%** |

Модель превзошла baseline по BLEU, сохранила практически такой же chrF и стала значительно чаще использовать современную лексику. Доля дословного копирования снизилась примерно на 45 процентных пунктов.

## Подход

1. Длинные исходные фрагменты и их переводы разбиваются на согласованные пары предложений.
2. Удаляются дубликаты, неизменённые пары и различия только в регистре или пунктуации.
3. Сохраняются примеры, в которых целевой текст содержит явный маркер современной речи.
4. Разбиение выполняется по исходным фрагментам, чтобы избежать утечки между выборками.
5. `cointegrated/rut5-small` дообучается с помощью взвешенной token-level cross-entropy.

Стандартный loss сильнее поощряет копирование многочисленных неизменённых слов, чем редкие стилистические замены. Поэтому токены целевого текста, отсутствующие во входном предложении, получают вес `3.0`, а остальные - вес `1.0`.

## Данные

Исходный датасет содержит 3 613 пар фрагментов русской классической прозы и их современных переложений. После выравнивания предложений, фильтрации, проверки длины и удаления дубликатов осталось 8 845 пар.

| Выборка | Количество пар |
|---|---:|
| Train | 7 025 |
| Validation | 915 |
| Test | 905 |

Предложения из одного исходного фрагмента всегда находятся в одной выборке. Это предотвращает утечку похожего контекста между train, validation и test.

## Развитие эксперимента

- При обучении на длинных фрагментах около 88% примеров обрезалось.
- Переход к предложениям устранил обрезание, но модель в основном копировала вход.
- Фильтрация по стилевым маркерам усилила полезный обучающий сигнал.
- Взвешенная функция потерь заметно снизила долю копирования.
- Вес новых токенов `3.0` дал лучший баланс между изменением стиля и сохранением смысла.

## Метрики

- **BLEU** и **chrF** оценивают сходство с эталонным переложением.
- **Style marker rate** показывает долю предсказаний с современной лексикой.
- **Marker recall** измеряет долю стилевых маркеров эталона, воспроизведённых моделью.
- **Exact copy rate** показывает, как часто модель полностью копирует исходное предложение.

Автоматические метрики рассматриваются вместе с примерами генерации, поскольку они не могут полностью оценить естественность речи и сохранение смысла.

## Запуск

Ноутбук рассчитан на Google Colab с GPU:

1. открыть `notebooks/style_transfer.ipynb` в Colab;
2. выбрать GPU runtime;
3. выполнить все ячейки сверху вниз.

Датасет загружается автоматически. Лучший checkpoint выбирается по validation score, объединяющему marker recall и chrF.
